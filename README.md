# Shoplly

Shoplly is an AI-powered image search platform that enables semantic product discovery using OpenAI CLIP embeddings. Users can search products using either text descriptions or images and receive visually similar results.

## Features

- AI-powered semantic image search
- Text-to-image product retrieval
- Image-to-image similarity search
- Product management dashboard
- Supabase cloud storage integration
- Flask-based web interface

## Tech Stack

- Python
- Flask
- PyTorch
- OpenAI CLIP
- Supabase
- NumPy & Pandas

pip install -r requirements.txt
python app.py
